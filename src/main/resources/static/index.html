            环境
            
      
            
        
            留空用 PATH 里的 mvn。填 bin\mvn.cmd 或整个安装目录都行 —— 目录会自动往下找 bin
            
        
      
            
      
            
        
            留空继承当前环境
            
        
      
            
      
            
        
            默认读取 ~/.m2/settings.xml
            
        
      
            
      
            
        
            透传 -Dmaven.repo.local
            
        
      
            
    
            

    
            
      
            扫描选项
            
      
            
        
            
          
          
            透传 -o，完全不访问远程仓库。只在依赖都已缓存在本地时开；开了以后 BOM / build extension 解析不了的项目会直接失败。
            
        
            
        
      
            
      
            
        
            逗号分隔，逐个透传 -P
            
        
      
            
    
            

    
            
      
            Maven 子进程
            
      
            
        
            
          
          
            给 MAVEN_OPTS 注入 -Xmx。自动 = 按物理内存分档；不注入 = 交给 Maven 自己算（物理内存 / 4，大机器上会很贪）。你自己的 MAVEN_OPTS 已含 -Xmx 时不覆盖
            
        
            
        
      
            
      
            
        
            
          
          
            透传 Maven 的 -T，多模块项目按模块并行解析。串行最稳；并行会快一些，但模块树里的行序与「version managed from」这类注记挂在哪一行会变（计数与结论不变）。2C / 4C 表示按核数换算
